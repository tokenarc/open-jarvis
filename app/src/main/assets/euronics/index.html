☁️ Euronics Cloud Account & Sync
V32 · Local data preserved
EURONICS CLOUD
Engineer Login
Login karke apna private cloud data sync karein. Skip karne par app offline/local mode mein chalega; aapka local data safe rahega.
Setup required. Your existing reports remain saved on this device. Cloud sync is not active until a Firebase project is configured.

1. Firebase project settings

Firebase Console → Project settings → Your apps → Web app config. Ye web config secret key nahi hota; kabhi bhi Service Account JSON/private key yahan paste na karein.

2. Engineer account

Each engineer should use their own email account. Enable Email/Password in Firebase Authentication before creating accounts.

3. Sync and conflict safety

Sync includes localStorage keys beginning euronics_ and travelExpenseV12. Data is split into smaller private Firestore documents to avoid the 1 MiB per-document limit. Photos saved inside local report data can sync; separately downloaded JPG/PDF files are not uploaded by this Spark-only version. Conflicts are not silently overwritten.

Safety note: cloud sync requires Firebase config, Email/Password enablement, Firestore, and the supplied Firestore rules. Firebase Storage is not used by this Spark-compatible build. Existing local save/report features do not depend on Firebase.
